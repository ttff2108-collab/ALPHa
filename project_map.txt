خريطة مشروع: منصة Alpha Trading Platform

1. نظرة عامة على المشروع (الموقع عبارة عن إيه؟)
هذا المشروع هو منصة ويب متكاملة موجهة للمتداولين، وتحديداً متداولي استراتيجية SMC (Smart Money Concept). المنصة تقدم أدوات متعددة لمساعدة المتداولين مثل:
- حاسبة إدارة المخاطر (SMC Calculator).
- يوميات تداول خاصة (Trading Journal) لتسجيل الصفقات.
- غرفة بث مباشر (Live Room) للتداول الجماعي.
- معرض لمشاركة الصفقات والتحليلات (Gallery).
- نظام إحالة وعمولات.
- نظام دفع بالعملات الرقمية (Crypto Payment) للاشتراكات.
- حماية للمحتوى التعليمي من القرصنة.

2. لغات البرمجة والتقنيات المستخدمة
- الواجهة الخلفية (Backend - الخادم): لغة Python باستخدام إطار عمل Flask.
- الواجهة الأمامية (Frontend - العميل): HTML لبناء هيكل الصفحات، CSS (بأسلوب Glassmorphism العصري) للتنسيق والتصميم، و JavaScript لبرمجة التفاعلات وربط الصفحات بالخادم.
- قواعد البيانات: يتم استخدام ملفات JSON كقاعدة بيانات محلية بسيطة وخفيفة لتخزين البيانات.

3. شرح مفصل لهيكلة الملفات والمجلدات

أولاً: الملفات الرئيسية (في المجلد الجذري للمشروع)
- app.py: هو القلب النابض للمشروع. مكتوب بلغة Python ويحتوي على خادم Flask. يقوم بإدارة الروابط (Routes)، استقبال طلبات المستخدمين، التحقق من الصلاحيات، والتحكم في حفظ وجلب البيانات من ملفات الـ JSON.
- ملفات الـ JSON (مثل users.json, journal.json, gallery.json...): تعمل كقاعدة بيانات للمشروع، حيث يتم تخزين حسابات المستخدمين، صفقاتهم، الرسائل، والاعدادات.
- requirements.txt: يحتوي على المكتبات البرمجية التي يحتاجها المشروع ليعمل (مثل Flask وغيرها).
- ملفات التوثيق (.md و .txt): ملفات نصية تشرح النظام والمميزات (مثل SYSTEM_GUIDE.md).
- share_publicly.bat: سكربت مخصص غالباً لتشغيل الخادم ومشاركته على شبكة محلية أو عامة.

ثانياً: مجلد القوالب (templates)
يحتوي على جميع صفحات HTML التي يراها المستخدم:
- index.html: الصفحة الرئيسية الترويجية للموقع (Landing Page).
- login.html: صفحة تسجيل الدخول وإنشاء الحساب.
- home.html: لوحة تحكم المستخدم (Dashboard) بعد تسجيل الدخول (تحتوي على حاسبة SMC).
- admin.html / admin_payments.html: لوحة تحكم الإدارة للتحكم في المستخدمين والمدفوعات والمحتوى.
- journal.html: صفحة يوميات التداول لتسجيل تفاصيل وملاحظات الصفقات.
- gallery.html: صفحة معرض الصفقات لمشاهدة صفقات الآخرين.
- live.html: صفحة البث المباشر وغرفة الدردشة.
- course.html: صفحة المحتوى التعليمي والكورسات.
- buy.html / buy-crypto.html: صفحات الدفع لتجديد الاشتراك.
- chart.html: صفحة الرسوم البيانية (Charts).
- profile.html: صفحة الملف الشخصي للمستخدم.
- expired.html: تظهر للمستخدمين الذين انتهى اشتراكهم لمنعهم من الدخول للمحتوى المدفوع.
- chat.html: واجهة الدردشة.

ثالثاً: مجلد الملفات الثابتة (static)
يحتوي على ملفات التصميم والبرمجة النصية التي تعمل في متصفح المستخدم:
- style.css: يحتوي على أكواد التصميم والألوان لكل الموقع ويجعل شكله جذاباً.
- chat.css: تصميم خاص بصفحات الدردشة لتبدو متناسقة.
- script.js: ملف الجافاسكربت الرئيسي، يقوم بالعديد من المهام مثل إرسال واستقبال البيانات من الخادم (app.py) بدون إعادة تحميل الصفحة (AJAX/Fetch)، ويحتوي على العمليات الحسابية الخاصة بـ SMC.
- chat.js: مسؤول عن تشغيل الدردشة الحية وتحديث الرسائل تلقائياً.
- protection.js: يحتوي على أكواد لمنع سرقة المحتوى (مثل منع النقر بزر الماوس الأيمن أو النسخ أو الطباعة).
- مجلد uploads/: تُحفظ فيه الصور والملفات التي يرفعها المستخدمون من خلال الموقع (مثل صور الصفقات).

4. كيف تترابط هذه الملفات؟ (آلية عمل الموقع)
1. المستخدم يفتح المتصفح: عندما يطلب المستخدم رابط الموقع، يقوم الخادم (app.py) بتلقي هذا الطلب.
2. تجميع الصفحة: يقرأ (app.py) صفحة الـ HTML المناسبة من مجلد (templates) ويرسلها لمتصفح المستخدم.
3. التصميم والتفاعل: متصفح المستخدم يقوم بتحميل الصفحة، ويستدعي معها ملفات التصميم (css) وملفات البرمجة (js) من مجلد (static) ليتم عرض الموقع بشكله النهائي.
4. العمليات الديناميكية: إذا قام المستخدم بإجراء معين (مثل حفظ صفقة جديدة أو إرسال رسالة في الدردشة)، يقوم ملف (script.js) بإرسال هذا الطلب "في الخلفية" إلى (app.py).
5. حفظ البيانات: يقوم (app.py) بمعالجة الطلب، وتحديث ملفات البيانات المناسبة (مثل حفظ الصفقة في journal.json)، ثم يرد على المتصفح بنجاح العملية ليتم تحديث الصفحة أمام المستخدم دون الحاجة لعمل Refresh.
